# Konfiguration

Alle Laufzeiteinstellungen werden über Umgebungsvariablen gelesen.

## Allgemein

| Variable | Bedeutung | Beispiel |
| --- | --- | --- |
| `PORT` | HTTP-Port | `8000` |
| `HTTPS` | Setzt das Secure-Flag des Sitzungscookies; für HTTP lokal `false`, für HTTPS `true` | `true` |
| `TIMEZONE` | Zeitzone für Cronjobs | `Europe/Berlin` |

## Datenbanken

| Variable | Bedeutung |
| --- | --- |
| `DATABASE_URL` | PostgreSQL-Verbindungszeichenfolge; in Compose muss der Hostname `postgres` sein |
| `POSTGRES_DB` | Datenbankname für Compose |
| `POSTGRES_USER` | PostgreSQL-Benutzer für Compose |
| `POSTGRES_PASSWORD` | PostgreSQL-Passwort für Compose |
| `REDIS_URL` | Adresse des KeyDB-/Redis-Servers im Format `host:port` |
| `REDIS_PASSWORD` | Optionales Passwort |

## Benachrichtigungen

| Variable | Bedeutung |
| --- | --- |
| `NOTIFICATION_PRIORITY` | Wird aktuell vom Server nicht ausgewertet; Ablaufbenachrichtigungen verwenden für Gotify Priorität `8`, ntfy setzt sie auf `5` |
| `NOTIFICATION_CRON` | Durch Semikolon getrennte Cron-Ausdrücke mit Sekunden |

Der Standardzeitplan `0 0 8 * * *;0 0 18 * * *` prüft Produkte täglich um 08:00 und 18:00 Uhr in der mit `TIMEZONE` angegebenen Zeitzone. Die Prüfung meldet Produkte, die bereits abgelaufen sind oder innerhalb der nächsten sieben Tage ablaufen.

## LLM-Anbieter

`LLM_PROVIDER` unterstützt `openai`, `anthropic` und `custom`.

```dotenv
# OpenAI
LLM_PROVIDER=openai
LLM_LANGUAGE=DEUTSCH
OPENAI_API_KEY=<key>
OPENAI_MODEL=<model>
```

```dotenv
# Anthropic
LLM_PROVIDER=anthropic
LLM_LANGUAGE=DEUTSCH
ANTHROPIC_API_KEY=<key>
ANTHROPIC_MODEL=<model>
```

```dotenv
# OpenAI-kompatibler Anbieter
LLM_PROVIDER=custom
LLM_LANGUAGE=DEUTSCH
CUSTOM_BASE_URL=<base-url>
CUSTOM_MODEL=<model>
CUSTOM_KEY=<key>
```

Verwende starke Datenbankpasswörter und sichere API-Schlüssel.
Committe keine `.env`-Datei oder echten Zugangsdaten.

Für Docker Compose werden die Variablen aus `.env` geladen. `POSTGRES_DB`, `POSTGRES_USER` und `POSTGRES_PASSWORD` müssen zu `DATABASE_URL` passen; als Datenbankhost ist dort `postgres` einzutragen.
