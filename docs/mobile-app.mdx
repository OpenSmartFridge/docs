# Mobile App

Die mobile App ist eine Expo-/React-Native-Anwendung für Android und iOS; Expo Web ist ebenfalls konfiguriert.
Sie verbindet sich mit einer OpenSmartFridge-Serverinstanz und nutzt deren `/api`-Endpunkte.

## Technologien

- Expo 58
- React 19.3 und React Native 0.88
- React Native Paper 5
- Expo Camera, Expo Clipboard und React Native Paper Dates
- AsyncStorage für Serveradresse, Sitzungscookie und lokalen Anmeldestatus

## Projektstruktur

```text
App.js                 Theme, Provider und App-Einstieg
src/
├── components/         App-Bar, Navigation, Produkt- und Rezeptkarten
├── context/            Gemeinsamer Anwendungszustand
├── lib/                API- und Cookie-Hilfsfunktionen
└── pages/               Login, Registrierung, Produkte, Rezepte und Profil
```

Die App stellt nach der Anmeldung die Tabs **Produkte**, **Rezepte** und **Profil** bereit. Das helle oder dunkle Theme wird automatisch anhand des Systemmodus gewählt.
