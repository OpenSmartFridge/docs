# Mobile App installieren

## Voraussetzungen

- Node.js und npm
- Android- oder iOS-Gerät/Emulator; für die Webversion einen unterstützten Browser
- Expo Go zum Testen oder eine native Entwicklungsumgebung für lokale Builds
- Eine erreichbare OpenSmartFridge-Serverinstanz

## Entwicklung starten

Im Verzeichnis des Mobile-Repositories:

```bash
npm install
npm start
```

Expo startet den Entwicklungsserver. Öffne die App anschließend mit Expo Go oder in einem Emulator.
Für die Webversion:

```bash
npm run web
```

Für lokale native Builds:

```bash
npm run android
```

Für native iOS-Builds:

```bash
npm run ios
```

## Expo Application Services

`eas.json` enthält die Buildprofile `development`, `preview` und `production`. Die App enthält bereits Owner und EAS-Projekt-ID. Preview und Production erzeugen für Android eine APK; Production erhöht die App-Version remote automatisch.
Melde dich zuerst beim EAS-Konto an:

```bash
npx eas-cli login
npx eas-cli build --profile preview --platform android
npx eas-cli build --profile production --platform android
```

## Serveradresse

Auf der Login- und Registrierungsseite wird die Server-Base-URL eingegeben. Die Adresse wird lokal mit AsyncStorage gespeichert und sollte das Schema enthalten:

```text
https://smartfridge.example.com
```

Verwende bei einer öffentlich erreichbaren Serverinstanz HTTPS.
