# OpenSmartFridge

OpenSmartFridge verwaltet Produkte, Ablaufdaten, Rezepte und Benutzer.
Der Server besteht aus einem Go-Backend mit integrierter React-Weboberfläche und verwendet PostgreSQL sowie KeyDB.

## Funktionen

- Produkte manuell oder per Barcode erfassen
- Ablaufdaten anzeigen und bearbeiten
- Ernährungseinstellungen für KI-generierte Rezepte hinterlegen
- Rezepte aus dem aktuellen Produktbestand generieren
- Generierte Rezepte speichern und erneut anzeigen
- Als Administrator Benutzer verwalten; persönliche API-Schlüssel für den Produktzugriff erstellen
- Gotify- oder ntfy-Benachrichtigungen für bald ablaufende Produkte per API konfigurieren

## Systemübersicht

Der Go-Server liefert die REST-API und das gebaute React-Frontend aus.
PostgreSQL speichert die Anwendungsdaten. KeyDB dient als Cache.

```text
Browser
  |
  | HTTP / API
  v
Go-Server + React-Dateien
  |          |
  v          v
PostgreSQL  KeyDB
```

## Voraussetzungen

- Docker mit Docker Compose für den empfohlenen Betrieb
- Alternativ: Go 1.26.5, Node.js 24, PostgreSQL 17 und KeyDB
- Einen API-Schlüssel für OpenAI, Anthropic oder einen OpenAI-kompatiblen Anbieter
